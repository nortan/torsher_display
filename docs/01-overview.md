# 1. Архитектура и структура

## Из чего состоит проект

```
index.html, app.js, styles.css   Экран (плеер). Swiper 14 переключает слайды, GSAP 3.15 анимирует.
admin/                           Панель управления (Bootstrap 5.3), одна страница без сборки.
api/                             Бэкенд PHP 8.1+: данные, вход, фото, FTP, установка.
sql/                             Схемы БД: MySQL (бой) и SQLite (разработка).
data/                            Файловое хранилище (режим «в файлах»), закрыто от веба.
shared/model.js                  Общая модель: раскладки, эффекты, генератор слайдов, расписания.
content/data.json                Стартовые данные и данные статической сборки.
assets/fonts, assets/img,        Шрифты (локально), логотип, демо-фото блюд (WebP с прозрачностью).
assets/dishes
vendor/                          GSAP, Swiper, Bootstrap, JSZip — лежат в репозитории, CDN не нужен.
tools/                           build.mjs (сборка), deploy.sh (rsync), docs.mjs (таблицы в docs).
docs/                            Эта документация.
.github/workflows/               pages.yml (GitHub Pages), deploy-server.yml (rsync по SSH).
```

## Как это работает

```
 Панель управления (admin/)  ──PUT api/data.php──►  MySQL  ◄──GET api/data.php──  Экран (index.html)
        │                                                                             ▲
        ├── ZIP-сборка (в браузере) ──────────────────────────────► любой веб-сервер / флешка
        ├── Коммит в GitHub ──► GitHub Actions ──► GitHub Pages / rsync на сервер ─────┤
        └── FTP (делает сервер: api/deploy.php) ──► удалённый хостинг ─────────────────┘
```

### Экран (`index.html`)

- Холст 1080×1920 масштабируется под фактический вьюпорт. При небольшом расхождении пропорций
  (±10%) холст растягивается по высоте, раскладка на flex это поглощает.
- Данные: сначала `api/data.php` (если есть PHP), иначе `content/data.json`, при запуске
  с диска — `content/data.js`. Последние данные кешируются в `localStorage` на случай
  пропадания сети.
- Раз в `settings.refreshInterval` секунд экран перечитывает данные и пересобирает слайдер,
  только если итоговый HTML изменился. При смене версии в `build.json` страница
  перезагружается. Раз в сутки (`settings.dailyReloadAt`) экран перезагружается сам.
- Слайды фильтруются по расписанию показа (дни, время, даты). Афиша сама пересчитывает события
  на неделю или на две.
- На каждый показ слайда создаётся `gsap.context`, при уходе слайда он откатывается
  (`ctx.revert()`), так что память не утекает.
- Режим предпросмотра `?preview=1`: данные приходят из админки через `postMessage`.

### Панель управления (`admin/`)

- **Серверный режим** (есть `api/`): вход по логину. Правки копятся в черновике браузера,
  кнопка «Опубликовать на экраны» сохраняет их в MySQL. Фото загружаются в `uploads/`.
- **Локальный режим** (нет PHP, например GitHub Pages): данные хранятся в `localStorage`,
  фото — в IndexedDB. Публикация через ZIP, JSON или коммит в GitHub.
- Предпросмотр — настоящий плеер в `iframe`.

### Сервер (`api/`)

| Файл | Назначение |
|---|---|
| `lib.php` | Конфиг, PDO, JSON, сессии, CSRF, работа с таблицами MySQL, шифрование секретов |
| `storage.php` | Слой хранения: база данных или файлы (`data/*.json`), перенос между ними |
| `store.php` | Текущий режим хранения и переключение с переносом данных |
| `data.php` | GET — данные для экрана (публично), PUT — сохранение (вход и CSRF) |
| `auth.php` | Вход, выход, смена пароля |
| `upload.php` | Загрузка фото: PNG, WebP, JPEG, до 8 МБ |
| `deploy.php` | Настройки FTP, проверка соединения, сборка и выгрузка по FTP/FTPS |
| `install.php` | Первичная установка: таблицы, администратор, стартовые данные |
| `config.sample.php` | Образец `config.php` (сам `config.php` в git не хранится) |

## Библиотеки

| Библиотека | Версия | Лицензия |
|---|---|---|
| GSAP (+ SplitText, CustomEase, ScrambleTextPlugin) | 3.15.0 | Standard «no charge» — бесплатно, в том числе для коммерции |
| Swiper | 14.2.0 | MIT. Используется `swiper-bundle.min.js`, CSS переписан без nesting в `vendor/swiper/swiper-flat.css` |
| Bootstrap | 5.3.8 | MIT (только админка) |
| JSZip | 3.10 | MIT / GPLv3 (ZIP-сборка в админке) |
| Шрифты Nunito, Comfortaa, Montserrat, Carlito | — | SIL OFL 1.1 |

Нужен браузер Chrome или Edge 111+, Safari 16.4+ или Firefox 113+: этого требуют Swiper 14,
`color-mix()` и CSS `translate`/`scale`/`rotate`.
