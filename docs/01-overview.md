# 1. Архитектура и структура

## Из чего состоит проект

```
index.html, app.js, styles.css   Экран-плеер: Swiper переключает слайды, GSAP их анимирует.
admin/                           Одностраничная панель управления на Bootstrap 5.3.
api/                             PHP-бэкенд: вход, данные, фото, FTP и установка.
sql/                             Схемы MySQL и SQLite.
data/                            Файловое хранилище (закрыто от веба).
shared/model.js                  Общая модель раскладок, эффектов, дисплеев и настроек.
content/data.json                Стартовые данные и источник статической сборки.
assets/, vendor/                 Локальные фото, шрифты и библиотеки; CDN не нужен.
tools/                           Сборка, публикация и генерация справочника.
docs/                            Документация.
.github/workflows/               GitHub Pages, rsync/SSH и FTP-выкладка.
```

## Как это работает

```
admin/ ──► api/data.php ──► хранилище (MySQL или files) ──► index.html
   ├── ZIP-сборка ──► веб-сервер или флешка
   ├── GitHub ──► Pages / rsync
   └── FTP ──► удалённый хостинг
```

### Экран

- Логический холст — 1080×1920 для вертикали и 1920×1080 для горизонтали. `resolution: 1920`
  оставляет базовый физический размер, `3840` удваивает его; все элементы масштабируются вместе.
- `?display=<id>` выбирает ориентацию, разрешение и программу дисплея. Без параметра сохраняется
  прежнее поведение: все включённые слайды вертикально.
- Данные загружаются из `api/data.php`, затем `content/data.json` или `content/data.js` при запуске
  с диска. Последняя версия хранится в `localStorage` как резерв.
- Экран периодически проверяет обновления, отслеживает `build.json` и перезагружается по расписанию.
  Каждый показ слайда получает свой `gsap.context`, который откатывается при уходе слайда.
- В `?preview=1` админка передаёт данные плееру через `postMessage`.

### Панель управления

В серверном режиме правки сохраняются в черновик браузера и попадают на экраны после публикации.
В локальном режиме данные хранятся в `localStorage`, фото — в IndexedDB; результат публикуется ZIP,
JSON или коммитом в GitHub. Предпросмотр использует настоящий плеер в `iframe`.

### Сервер (`api/`)

| Файл | Назначение |
|---|---|
| `lib.php` | Конфиг, PDO, JSON, сессии, CSRF и общие функции |
| `storage.php`, `store.php` | Хранилище MySQL или files и переключение между режимами |
| `data.php`, `update.php` | Чтение, публикация и обновление данных из репозитория |
| `auth.php` | Вход, выход и смена пароля |
| `upload.php` | Загрузка PNG, WebP и JPEG до 8 МБ |
| `deploy.php` | Настройки и выгрузка по FTP/FTPS |
| `install.php` | Первичная установка и стартовые данные |
| `config.sample.php` | Образец; `api/config.php` в git не хранится |

## Библиотеки и требования

GSAP 3.15.0, Swiper 14.2.0, Bootstrap 5.3.8 и JSZip находятся в `vendor/`; шрифты — в
`assets/fonts`. Нужен Chrome/Edge 111+, Safari 16.4+ или Firefox 113+.
