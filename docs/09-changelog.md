## Принятые решения

- **Библиотеки лежат в репозитории**, CDN не используется: экран в кафе должен работать без интернета.
- **CSS Swiper переписан без nesting** (`vendor/swiper/swiper-flat.css`): встроенные браузеры ТВ
  не понимают `&`.
- **Calibri не распространяется** (лицензия Microsoft): используется системный, иначе Carlito.
- **Одна модель на всех** (`shared/model.js`): экран, админка и сборка не расходятся.
- **Публикация целиком** (полная замена данных в транзакции): проще и надёжнее построчных правок
  для объёмов кафе.
- **Анимация — на каждый показ слайда** (`gsap.context` + `revert`), чтобы ТВ-браузер не копил память
  за дни работы. Фоновые эффекты работают только у активного слайда.
