# Памятка для статической сборки

Сборка — автономный сайт: плеер читает `content/data.json`, а при открытии с диска — копию
`content/data.js`. Полные варианты публикации описаны в [06-publishing.md](06-publishing.md).

## Размещение

1. Распакуйте сборку в каталог сайта. Подойдут nginx, Apache, Caddy, хостинг статики или
   `python3 -m http.server 8080` для проверки.
2. На ТВ или мини-ПК откройте адрес в киоск-режиме:

   ```bash
   chromium --kiosk --noerrdialogs --disable-infobars --start-fullscreen http://SERVER/
   ```

3. По умолчанию используется вертикальный 2K-холст 1080×1920. Ориентация и разрешение задаются
   для каждого дисплея в админке; вертикальный 4K — 2160×3840. Поворот вывода задаётся в ОС или ТВ.

Для обновления загрузите новую сборку поверх старой. Экран перечитает данные через интервал из
админки («Работа экрана») и перезагрузится при изменении версии в `build.json`.

## Без сервера и клавиши

`index.html` можно открыть с диска или флешки. На экране доступны: `F` — полный экран,
`R` — перечитать данные, `←`/`→` — листать слайды.

Требуется Chrome/Edge 111+, Safari 16.4+ или Firefox 113+.
