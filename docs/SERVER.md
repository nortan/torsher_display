# Статическая сборка витрины

Это готовый сайт без серверной логики: экран крутит слайды автономно.
Данные — в `content/data.json` (и копия в `content/data.js` для запуска без сервера).

## Вариант 1. Любой веб-сервер (рекомендуется)

1. Распакуйте сборку в каталог сайта, например `/var/www/torsher-display`.
2. Для nginx — пример в `nginx.conf.example`. Подойдут также Apache, Caddy,
   любой хостинг статики или `python3 -m http.server 8080`.
3. На ТВ / мини-ПК откройте адрес сайта в браузере в режиме киоска:

   ```
   chromium --kiosk --noerrdialogs --disable-infobars --start-fullscreen http://SERVER/
   ```

   Экран вертикальный FullHD (1080×1920): поверните вывод в настройках ОС
   (`xrandr --output HDMI-1 --rotate left`) или в меню телевизора.

**Обновление.** Загрузите новую сборку поверх старой. Экран сам перечитывает
`content/data.json` (интервал — в админке, «Работа экрана») и перезагружается,
если изменилась версия в `build.json`.

## Вариант 2. Без сервера

Откройте `index.html` прямо с диска или флешки — данные возьмутся из `content/data.js`.

## Горячие клавиши на экране

- `F` — полноэкранный режим (или двойной клик)
- `R` — перечитать данные
- `←` / `→` — листать слайды

Требуется браузер Chrome/Edge 111+, Safari 16.4+ или Firefox 113+.
