# 2. Установка на сервер (PHP + MySQL)

## Требования

- PHP 8.1+ с расширениями `fileinfo`, `sodium`, `ftp` (последнее — для выгрузки по FTP); для MySQL ещё `pdo_mysql`.
- **Хранилище на выбор:** MySQL 5.7+ или MariaDB 10.3+ — **или файлы на сервере** (база не нужна).
- Право на запись в папку `uploads/`, а для файлового режима — в папку данных (`data/`).
- Для сборки нужен Node.js 18+ (не обязательно: можно залить репозиторий как есть).

## Где хранятся данные

| Режим | Что хранится где |
|---|---|
| `db` — в базе данных | Таблицы MySQL (`sql/schema.mysql.sql`) |
| `files` — в файлах | JSON-файлы в папке `data/` (или в `data_dir` из `config.php`): `site.json`, `users.json`, `options.json`, `media.json` и `storage.json` с текущим режимом |

Режим выбирается при установке и **переключается в админке** (Публикация → «Хранение данных»).
При переключении все данные (блюда, мероприятия, слайды, пользователи, настройки FTP, реестр фото)
переносятся в выбранное хранилище; старое хранилище не удаляется. Папку `data/` лучше вынести
за пределы веб-корня (`data_dir` — абсолютный путь). В репозитории она закрыта `.htaccess`.

## Шаги

1. **Сборка.** Команда `node tools/build.mjs --server` создаст в `dist/` полный сайт: экран,
   админку, `api/` и `sql/`. `config.php` в сборку не попадает никогда. Скопируйте содержимое
   `dist/` в корень сайта.
2. **База.** Создайте базу `utf8mb4` и пользователя с правами на неё.
3. **Конфиг.** Скопируйте `api/config.sample.php` в `api/config.php` и заполните:
   - `storage` — `db` или `files` (режим по умолчанию; выбор в админке важнее), `data_dir` — папка для файлового режима;
   - `db.dsn`, `db.user`, `db.password` — подключение к базе (для файлового режима не нужно);
   - `app_key` — случайная строка от 32 символов (`php -r "echo bin2hex(random_bytes(32));"`).
     Ею шифруется пароль FTP. Если ключ сменить, пароль FTP нужно ввести заново;
   - `uploads_dir`, `upload_max_bytes` — папка для фото и предельный размер файла.
4. **Установка.** Откройте `https://ваш-сайт/api/install.php`, выберите, где хранить данные
   (база данных или файлы), и задайте логин и пароль администратора. Будет создано хранилище,
   а стартовые данные загрузятся из `content/data.json`. Из консоли то же самое делает
   `php api/install.php admin 'пароль' [db|files]`.
5. **Закройте установщик:** в `config.php` поставьте `'install_enabled' => false`.
6. Готово: панель управления — `https://ваш-сайт/admin/`, экран — `https://ваш-сайт/`.

## Веб-сервер

- **Apache:** защита уже лежит в `.htaccess`. В `api/` закрыты `lib.php`, `storage.php` и `config*.php`,
  в `sql/` и `data/` закрыто всё, в `uploads/` запрещено выполнять скрипты.
- **nginx:** пример в [`nginx.conf.example`](nginx.conf.example). В нём нужно закрыть те же пути,
  подключить PHP-FPM и задать `client_max_body_size 10m` для загрузки фото.
- Данные (`api/data.php`, `content/*.json`, `build.json`) отдаются без кеша, статику
  (шрифты, JS, фото) можно кешировать.

## Экран в кафе

- Откройте адрес сайта в браузере в режиме киоска:
  `chromium --kiosk --noerrdialogs --disable-infobars --start-fullscreen https://ваш-сайт/`
- Поверните вывод на вертикальную ориентацию средствами ОС (`xrandr --output HDMI-1 --rotate left`)
  или в меню телевизора.
- Горячие клавиши: `F` — полный экран, `R` — перечитать данные, `←/→` — листать слайды.

## Обновление версии проекта

1. Сделайте резервную копию базы и папки `uploads/`.
2. Залейте новую сборку `dist/` поверх старой. `api/config.php` и `uploads/` не затираются:
   первого нет в сборке, во второй лежит только `.htaccess`.
3. Схема создаётся командами `CREATE TABLE IF NOT EXISTS`. Новые таблицы (например,
   `options`) и колонки (например, `extra`) создаются автоматически при первом обращении.
