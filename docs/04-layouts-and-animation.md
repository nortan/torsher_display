# 4. Справочник: раскладки, анимация, настройки

Таблицы ниже генерируются из `shared/model.js` командой `node tools/docs.mjs`: не правьте их руками.

## Как устроена анимация слайда

1. Swiper переключает слайд (`settings.transition`). На каждом показе запускается свой `gsap.context`.
2. Общая последовательность `animation` проигрывается по порядку: заголовок (SplitText),
   фото тарелок (`photoIn`), рамки блюд и строки (`preset`), названия (`name`), цены (`priceIn`),
   блок «Скоро у нас».
3. Постоянные эффекты (`photoLoop`, `priceLoop`, акцент, значок NEW, фоновый градиент) работают,
   пока слайд на экране.
4. Элементы, у которых в «Элементах слайда» задан свой эффект, выпадают из общей
   последовательности и анимируются отдельно, со своей длительностью и задержкой.
5. Смещения (`slide.elements[*].x/y`, `slide.photoPos[*]`) задаются CSS-свойствами
   `translate`/`scale`/`rotate`. Они складываются с `transform`, который анимирует GSAP.

Анимацию можно задать глобально (`settings.animation`) или для слайда целиком (`slide.animation`).
Для отдельного элемента — в `slide.elements`.

### Появление элементов слайда (`animation.preset`)

| Ключ | Название |
|---|---|
| `rise` | Подъём снизу из маски |
| `fade` | Мягкое проявление |
| `slide` | Выезд справа |
| `zoom` | Масштаб с пружиной |
| `flip` | 3D-переворот строк |
| `blur` | Фокусировка из размытия |
| `typewriter` | Печатная машинка |
| `cascade` | Каскад слева/справа |
| `none` | Без анимации |

### Заголовок слайда (`animation.title`)

| Ключ | Название |
|---|---|
| `chars` | По буквам |
| `words` | По словам |
| `lines` | По строкам |
| `none` | Без эффекта |

### Порядок появления (`animation.order`)

| Ключ | Название |
|---|---|
| `sequence` | По очереди: заголовок → фото → список |
| `together` | Всё вместе |
