# Документация витрины «Торшер»

Рекламная витрина кафе для **вертикального FullHD-экрана (1080×1920)** с панелью управления
и бэкендом PHP + MySQL. Здесь собраны все инструкции и описания проекта: по ним можно
установить, настроить, развивать проект и передать его на другой аккаунт.

| Документ | О чём |
|---|---|
| [01-overview.md](01-overview.md) | Архитектура, структура репозитория, как работают экран, админка и сервер |
| [02-install-server.md](02-install-server.md) | Установка на хостинг с PHP + MySQL, настройка Apache и nginx, обновление |
| [03-admin-guide.md](03-admin-guide.md) | Руководство по панели управления для сотрудников кафе |
| [04-layouts-and-animation.md](04-layouts-and-animation.md) | Справочник раскладок, эффектов GSAP, переходов, шрифтов и настроек |
| [05-data-model.md](05-data-model.md) | Формат `content/data.json`, таблицы MySQL, API |
| [06-publishing.md](06-publishing.md) | Публикация: сервер, FTP, ZIP, GitHub Pages, Git, rsync |
| [07-development.md](07-development.md) | Разработка: локальный запуск, проверки, как добавить раскладку или эффект |
| [08-handover.md](08-handover.md) | Передача проекта на другой аккаунт GitHub, хостинг или команду |
| [09-changelog.md](09-changelog.md) | История изменений и принятые решения |
| [SERVER.md](SERVER.md) | Краткая памятка к статической сборке (кладётся в каждую сборку) |
| [nginx.conf.example](nginx.conf.example) | Пример конфигурации nginx |

Документация поддерживается вместе с кодом: любое изменение возможностей сопровождается
правкой этих файлов (правило записано в [`CLAUDE.md`](../CLAUDE.md)). Справочные таблицы
в `04-layouts-and-animation.md` генерируются из кода командой `node tools/docs.mjs`.
