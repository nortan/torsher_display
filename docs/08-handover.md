# 8. Передача проекта на другой аккаунт

Всё нужное для работы лежит в репозитории: код, библиотеки, шрифты, демо-данные и эта документация.
Внешних зависимостей нет: CDN не используется, `npm install` не нужен. Для сборки достаточно Node.js 18+,
для сервера — PHP 8.1+ и MySQL.

## Репозиторий GitHub

1. Передайте репозиторий (Settings → General → Transfer ownership) или сделайте форк либо копию:
   `git clone --mirror` → `git push --mirror` в новый репозиторий.
2. В новом репозитории:
   - Settings → Pages → Source: **GitHub Actions**; адрес сайта сменится на `https://<новый-владелец>.github.io/<репо>/`;
   - Settings → Secrets → Actions: при необходимости заново задайте `DEPLOY_TARGET`, `DEPLOY_SSH_KEY`
     и `DEPLOY_KNOWN_HOSTS` (секреты при передаче не копируются).
3. В админке (Публикация → «Публикация в Git») поменяйте владельца, репозиторий и токен. Значения
   по умолчанию (`nortan` / `torsher_display`) зашиты в `admin/admin.js` (`renderPublish`), их можно исправить там.

## Сервер PHP + MySQL

1. Сделайте резервную копию базы (`mysqldump`) и папки `uploads/`.
2. На новом хостинге выполните шаги из [02-install-server.md](02-install-server.md). Базу можно
   перенести дампом; тогда `install.php` не запускайте.
3. `api/config.php` в репозитории нет: создайте его заново. Если `app_key` сменился, пароль FTP
   в админке нужно ввести заново.
4. Пароли администраторов переносятся вместе с таблицей `users`. Иначе создайте нового через `install.php`
   на пустой базе.

## Локальный режим админки

Данные локального режима (без сервера) хранятся только в браузере: `localStorage` и IndexedDB.
Чтобы их перенести, сделайте в админке «Экспорт data.json» и затем «Импорт» на новом месте.
Фото из IndexedDB переносятся через ZIP-сборку или публикацию в Git. Локальный пароль (по умолчанию
admin / pass123) задаётся в каждом браузере отдельно.

## Что проверить после передачи

- [ ] Открывается экран, крутятся слайды, нет ошибок в консоли браузера.
- [ ] Вход в админку, публикация на экраны, загрузка фото.
- [ ] Проверка соединения FTP (если используется).
- [ ] GitHub Actions: `pages.yml` зелёный.
- [ ] Замените демо-фото блюд своими и поменяйте логотип, название и подпись в «Шапке экрана».
