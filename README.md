# Торшер — рекламная витрина кафе

Цифровое табло для **вертикального FullHD-экрана (1080×1920)**: меню с обтравленными фото блюд,
афиша мероприятий, бегущая строка и часы. Слайды переключает **Swiper 14**, анимацию делает
**GSAP 3.15** (SplitText, CustomEase). Админка сверстана на **Bootstrap 5**, бэкенд — **PHP + MySQL**.

```
index.html          плеер (экран)
admin/              панель управления (Bootstrap 5)
api/                бэкенд PHP: данные, вход, загрузка фото, выгрузка по FTP, установка
sql/                схема MySQL
content/data.json   стартовые данные / данные статической сборки
shared/model.js     общая модель: раскладки, пресеты анимаций, переходы, генератор слайдов
assets/dishes/      демо-фото блюд (обтравленные WebP с прозрачным фоном)
tools/              build.mjs — сборка dist/, deploy.sh — выгрузка по rsync
```

## Установка на сервер (PHP 8.1+ и MySQL 5.7+ / MariaDB 10.3+)

1. Соберите сайт: `node tools/build.mjs --server` (или возьмите репозиторий целиком).
   Скопируйте содержимое `dist/` в корень сайта.
2. Создайте базу и пользователя MySQL. Скопируйте `api/config.sample.php` в `api/config.php`
   и заполните: подключение к базе, `app_key` (случайная строка, ею шифруется пароль FTP).
3. Откройте `https://ваш-сайт/api/install.php` и задайте логин и пароль администратора.
   Будут созданы таблицы, а стартовые данные загрузятся из `content/data.json`.
   Из консоли то же самое делает `php api/install.php admin 'пароль'`.
   После установки поставьте `install_enabled => false`.
4. Панель управления: `https://ваш-сайт/admin/`, экран: `https://ваш-сайт/`.

Нужны расширения PHP `pdo_mysql`, `fileinfo`, `sodium`, `ftp`. У папки `uploads/` должно быть
право на запись. Для Apache защита служебных файлов уже лежит в `.htaccess`, для nginx пример
в `docs/nginx.conf.example`.

**Как это работает.** Правки в админке копятся в черновике браузера. Кнопка
«Опубликовать на экраны» записывает их в MySQL, а экраны читают `api/data.php` и обновляются
сами. Без PHP (статический хостинг, флешка) плеер берёт данные из `content/data.json`
(`content/data.js`), а админка переходит в локальный режим.

## Панель управления

- **Экраны** — слайды в порядке показа: включение, дублирование, удаление.
  Кнопка «Сгенерировать комбинации» собирает 24 слайда 19 разных видов.
  Настройки слайда:
  - заголовок: показывать ли, выравнивание, текст, подзаголовок;
  - раскладка и блюда в фото- и текстовых слотах;
  - **элементы слайда**: у каждого элемента (заголовок, рамка блюда, фото, список, «Скоро у нас»,
    афиша) включается показ, задаётся свой эффект GSAP, его длительность и задержка,
    а также **смещение X/Y** от штатного места;
  - **положение фото**: сдвиг, размер, поворот, зеркальное отражение;
  - размер текста на слайде; ближайшие мероприятия; расписание показа (дни, время, даты);
    общая анимация появления.
- **Блюда** — фото (только обтравленные, PNG/WebP с прозрачным фоном: без прозрачности
  админка предупредит и предложит убрать однотонный фон), название, описание, вес, цена,
  старая цена, метка.
- **Мероприятия** — дата, время, название, рубрика, описание, стоимость, фото, выделение.
  На афише у события видны число, день недели, время и название.
- **Анимация и оформление** — переход между слайдами (11 эффектов Swiper), появление
  информации (9 пресетов GSAP), **шрифты** и их размеры, тема, цвет, бегущая строка, работа экрана.
- **Публикация**:
  - на экраны (MySQL);
  - **выгрузка по FTP**: хост, порт, логин, пароль, папка, FTPS и пассивный режим. Сервер сам
    собирает статическую витрину и выгружает её; неизменившиеся файлы пропускаются;
  - ZIP-сборка, коммит в GitHub, экспорт и импорт `data.json`.

### Раскладки слайдов с блюдами

| Вид | Фото : текст |
|---|---|
| Текст списком · крупно · в две колонки · по категориям · главное в рамке | 0 : 6–10 |
| Одно блюдо крупно | 1 : 0 |
| Тарелка внизу · справа · сверху (афишный) | **1 : 2** |
| Тарелка слева · справа со списком · две колонки + тарелка | 1 : 4 · 1 : 6 · 1 : 8 |
| Зигзаг · по диагонали | **2 : 4** |
| Зигзаг · три тарелки внизу | **3 : 6** |
| Тарелки по углам | 4 : 4 |

## Другие способы публикации

- **ZIP из админки**: статическая витрина для любого веб-сервера или флешки
  (внутри `SERVER.md` и пример конфигурации nginx).
- **Git**: `pages.yml` публикует сайт на GitHub Pages, `deploy-server.yml` выгружает его
  по rsync/SSH, если заданы секреты `DEPLOY_TARGET` и `DEPLOY_SSH_KEY`.
- **Консоль**: `node tools/build.mjs` → `dist/`,
  `DEPLOY_TARGET=user@host:/var/www/display tools/deploy.sh`.

Экран обновляет данные сам (по умолчанию раз в 60 с), перезагружается при новой версии
(`build.json`) и раз в сутки в 04:00. Если сеть пропала, он показывает последние сохранённые данные.
Горячие клавиши на экране: `F` — полный экран, `R` — перечитать данные, `←/→` — листать слайды.

## Разработка

```bash
python3 -m http.server 8080          # только статика: админка в локальном режиме
php -S 127.0.0.1:8080 -t .           # с бэкендом (нужен api/config.php)
```

Для локальной разработки подойдёт SQLite: `'dsn' => 'sqlite:/tmp/torsher.sqlite'`
(схема `sql/schema.sqlite.sql`). В бою используется MySQL.

## Шрифты и лицензии

- Шрифты лежат локально: Nunito и Comfortaa (заголовки), Montserrat (названия и цены), Calibri (текст).
  Calibri — шрифт Microsoft, его нельзя распространять с сайтом: используется установленный
  в системе, а на ТВ и Linux — метрически совместимый Carlito (OFL).
- GSAP 3.15 бесплатен, в том числе для коммерческого использования
  ([Standard License](https://gsap.com/standard-license)). Swiper и Bootstrap распространяются под MIT,
  JSZip — под MIT/GPLv3.
- **Демо-фото блюд** вырезаны из присланного примера меню и обтравлены автоматически, только для
  демонстрации. Перед запуском замените их своими фотографиями в админке.

Нужен браузер Chrome или Edge 111+, Safari 16.4+ или Firefox 113+.
