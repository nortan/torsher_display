# Торшер — рекламная витрина кафе

Цифровое табло для **вертикального FullHD-экрана (1080×1920)**. На экране — меню с обтравленными
фото блюд, афиша, обратный отсчёт до мероприятия, объявления, бегущая строка и часы. Слайды
переключает **Swiper 14**, анимацию делает **GSAP 3.15**. Панель управления сверстана на
**Bootstrap 5**, бэкенд — **PHP + MySQL**. Работает офлайн: библиотеки и шрифты лежат в репозитории.

## Быстрый старт

```bash
python3 -m http.server 8080   # экран: http://localhost:8080/, админка: /admin/ (вход admin / pass123)
```

С бэкендом: `api/config.sample.php` → `api/config.php`, затем `php api/install.php admin 'пароль'`,
затем `php -S 127.0.0.1:8080 -t .`. Подробнее — в [docs/02-install-server.md](docs/02-install-server.md).

Демо-фото блюд взяты из присланного примера меню и обтравлены автоматически, только для
демонстрации. Перед запуском замените их своими.
