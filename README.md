# Торшер — рекламная витрина кафе

Цифровое табло для вертикального 2K-экрана (логический холст 1080×1920) с режимом 4K
(2160×3840). Витрина показывает меню, афишу, объявления и обратный отсчёт. Плеер использует
локальные Swiper 14 и GSAP 3.15, админка — Bootstrap 5, серверная часть — PHP 8.1+.
CDN не нужен: библиотеки и шрифты лежат в репозитории.

## Быстрый старт

Только экран и локальная админка:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`, админку — `/admin/` (локальный вход `admin / pass123`).
Для серверного режима скопируйте `api/config.sample.php` в `api/config.php`, затем выполните:

```bash
php api/install.php admin 'пароль'
php -S 127.0.0.1:8080 -t .
```

Полные инструкции и варианты публикации — в [docs/README.md](docs/README.md).

Демо-фото предназначены только для примера; перед запуском замените их своими.
